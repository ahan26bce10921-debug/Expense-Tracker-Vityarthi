# Project Statement: Expense Tracker System

## Problem Statement
Managing personal daily finances manually or on paper often leads to untracked expenditures, lack of categorical visibility, and human error in total budget calculations. Users need a simple, reliable, and lightweight tool to log, view, and organize their expenses effectively.

## Scope of the Project
Centered around personal expense management, this system allows users to:
1. Log individual expenditures with details (title, amount, and category).
2. Display all recorded expenses in a structured format.
3. Automatically calculate total expenditure.
4. Provide structured data handling and input validation to prevent runtime errors.

## Target Users
- Students managing personal monthly allowances.
- Budget-conscious individuals looking for a lightweight local tracking tool.
- Anyone looking for a straightforward command-line interface (CLI) or notebook-based finance manager.

## High-Level Features
- **Expense Addition Module:** Allows entering transaction details with automatic data formatting.
- **Expense Display Module:** Displays all logged entries in a clean tabbed table.
- **Analytics Module:** Calculates and reports cumulative spending.
- **Robust Input Handling:** Guarantees valid numerical input processing.
