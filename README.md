# Expense Tracker System

A Python-based personal finance application designed to log, categorize, and calculate daily expenses through a clean interactive interface. Built as part of the VITyarthi flipped course project evaluation.

---

## 📌 Project Overview
The **Expense Tracker System** solves the common problem of untracked personal expenditures. It provides an intuitive CLI and structured notebook environment allowing users to record transaction details, list logged items in tabular form, and instantly generate spending totals.

---

## ✨ Features
- **Add Expense:** Record new expenditures with title, monetary amount (₹), and category.
- **View All Expenses:** Display all logged entries in a clean, structured table format.
- **View Total Spent:** Compute total cumulative spending dynamically.
- **Interactive Navigation:** Menu-driven loop for seamless option selection.

---

## 🛠️ Tech Stack & Prerequisites
- **Language:** Python 3.x
- **Environment:** Jupyter Notebook / Standard Python CLI
- **Core Concepts:** Object-Oriented Programming (OOP), Data Structures (Lists & Objects), Formatting
